# Plano de Implementação - Cobquattu V2 (Local)

Este plano detalha as atualizações para transformar o site da Cobquattu em uma plataforma de inteligência territorial, seguindo as novas diretrizes institucionais.

## 1. Atualizações Globais e SEO (Fase 2)
- **index.html**: Atualizar metadados, título e adicionar schema markup para autoridade institucional.
- **Navbar.tsx**: Adicionar links para as novas páginas (Manifesto, Inteligência Territorial).
- **Footer.tsx**: Ajustar linguagem institucional e adicionar dados jurídicos (CNPJ simulado para estrutura).

## 2. Reestruturação do Hero (Fase 2)
- **HeroSection.tsx**: Implementar headline poderosa: "Inteligência Territorial para o Novo Nordeste" e subtítulo estratégico. Adicionar animações suaves.

## 3. Novas Seções na Home (Fase 3)
- **NordesteThesisSection.tsx**: Criar seção "A Tese do Nordeste" com dados visuais e mapas minimalistas.
- **Home.tsx**: Integrar as novas seções no fluxo da página.

## 4. Novas Páginas Institucionais (Fase 3)
- **Manifesto.tsx**: Página com a visão visionária e inspiradora da marca.
- **NordesteEstrategico.tsx**: Página com visão macroeconômica e vetores de crescimento.
- **App.tsx**: Configurar rotas para as novas páginas.

## 5. Centro de Inteligência Territorial (Fase 4)
- **Insights.tsx**: Transformar o Blog em uma página editorial premium.
- **BlogSection.tsx**: Renomear para "Insights" ou "Inteligência Territorial" na Home.

## 6. Ajuste de Linguagem (Fase 4)
- Revisar todos os componentes para substituir termos comerciais ("venda", "terrenos") por termos estratégicos ("estruturação", "ativos").
